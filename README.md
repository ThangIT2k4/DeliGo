
# 🍽️ DeliGo – Ứng dụng đặt món ăn & quản lý đơn hàng thông minh

## 🧭 Giới thiệu

**DeliGo** là một **ứng dụng di động** được phát triển với mục tiêu mang đến trải nghiệm **đặt món ăn nhanh chóng, tiện lợi và thông minh** cho người dùng.
Ứng dụng cho phép khách hàng dễ dàng **tìm kiếm nhà hàng, đặt món ăn, theo dõi trạng thái đơn hàng** và **thanh toán trực tuyến** – tất cả trong một nền tảng thống nhất.

DeliGo được phát triển bằng **ngôn ngữ Java** trên nền **Android**, tích hợp công nghệ hiện đại giúp nâng cao hiệu suất, tính ổn định và trải nghiệm người dùng.

---

## 🚀 Tính năng chính

### 👤 Dành cho khách hàng:

* 🔎 Tìm kiếm và xem menu của các nhà hàng gần bạn.
* 🍔 Đặt món ăn nhanh chóng chỉ với vài thao tác.
* 🧾 Theo dõi trạng thái đơn hàng theo thời gian thực.
* 💳 Hỗ trợ nhiều phương thức thanh toán (tiền mặt, ví điện tử, thẻ).
* ⭐ Đánh giá và phản hồi nhà hàng sau khi nhận hàng.

### 🏪 Dành cho nhà hàng / đối tác:

* 📦 Quản lý đơn hàng, trạng thái và thời gian giao hàng.
* 🧮 Theo dõi doanh thu, thống kê số lượng đơn hàng.
* 🧑‍🍳 Cập nhật thông tin menu, giá và hình ảnh món ăn.

## ⚙️ Cài đặt & chạy ứng dụng

### Yêu cầu hệ thống

* Android Studio **Arctic Fox** trở lên
* JDK 8+
* Thiết bị Android (API Level 24 trở lên)

### Cách cài đặt

```bash
# 1. Clone dự án về máy
git clone https://github.com/yourusername/deligo-app.git

# 2. Mở dự án bằng Android Studio

# 3. Cấu hình Firebase / API key (nếu có)

# 4. Build & Run ứng dụng
```
